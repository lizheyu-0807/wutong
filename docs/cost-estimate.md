# wutong 上线成本估算

## 先说结论

按年接诊 1.66 万例、工作日 60 例/天、周六 30 例/半天计算，wutong 不需要大服务器。云资源压力很小，主要成本在合规、安全、备份、审计和正式微信订阅消息接入。

建议预算：

| 预算类型 | 建议金额 |
|---|---:|
| 云资源最低预算 | 3,000-5,000 元/年 |
| 推荐正式试点预算 | 8,000-15,000 元/年 |
| 医院合规增强预算 | 15,000-30,000 元/年 |

实际采购价格以云厂商控制台为准。

## 业务量核算

| 项目 | 数值 | 计算说明 |
|---|---:|---|
| 年接诊人数 | 16,600 人/年 | 用户提供 |
| 工作日高峰 | 60 人/天 | 用户提供 |
| 周六高峰 | 30 人/半天 | 用户提供 |
| 平均每日 | 约 45 人/天 | 16,600 ÷ 365 |
| 每名患者后端请求 | 40-60 次 | 建档、看时间线、看详情、完成节点、提醒记录 |
| 年请求量 | 66 万-100 万次 | 16,600 × 40-60 |
| 月请求量 | 5.5 万-8.3 万次 | 年请求量 ÷ 12 |
| 高峰日请求 | 2,400-3,600 次/天 | 60 × 40-60 |
| 数据库存储 | 1-3GB/年 | 患者信息、节点状态、提醒记录、日志 |
| 图片/视频存储 | 10-100GB | 取决于宣教素材数量 |

结论：2 核 2G 可以跑，2 核 4G 更稳妥。

## 三档方案

| 方案 | 适合阶段 | 配置 | 月成本估算 | 年成本估算 | 结论 |
|---|---|---|---:|---:|---|
| A. 极简试点版 | 科室内部试跑 | CloudBase 小套餐 + 云存储 | 20-200 元 | 300-2,500 元 | 能跑，不建议承载正式医疗数据 |
| B. 推荐上线版 | 单科室正式试点 | CloudBase 标准版或 2核4G服务器 + 托管数据库 | 500-1,200 元 | 6,000-14,000 元 | 最适合第一版 |
| C. 合规增强版 | 医院较严要求 | 2核4G/4核8G + 托管 MySQL + COS + 备份 + 审计 | 1,200-2,500 元 | 14,000-30,000 元 | 更稳，第一版可能偏重 |

## 推荐采购组合

| 阶段 | 推荐组合 | 年费用估算 |
|---|---|---:|
| 内部演示 | CloudBase 小套餐 + 小程序认证 | 300-2,500 |
| 单科室试点 | CloudBase 标准版 + 云存储 + 日志 + 备份 | 3,500-6,000 |
| 正式上线推荐 | 2核4G 后端 + MySQL 1核2G + COS/CDN + 备份 | 5,500-9,000 |
| 合规增强 | 2核4G/4核8G + MySQL 2核4G + 审计备份 | 12,000-30,000 |

## 不建议省掉的项目

| 项目 | 原因 |
|---|---|
| 数据库备份 | 医疗数据误删后必须能恢复 |
| 操作审计 | 医护后台修改和导出需要追责 |
| HTTPS | 小程序服务域名和医疗数据传输都需要 |
| 订阅消息授权流程 | 没有授权就不能可靠提醒患者 |
| 对象存储 | 宣教图片和视频不应塞进数据库 |

## 成本风险

- 视频素材越多，对象存储和流量成本越高。
- 如果医院要求私有化部署，服务器和运维费用会明显上升。
- 如果要求等保、渗透测试、安全测评，费用不属于普通云资源成本。
- 当前估算不包含开发人力成本。
