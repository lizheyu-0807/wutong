# wutong 操作说明

## 打开应用

1. 打开终端。
2. 输入：
   ```powershell
   cd C:\Users\Administrator\Documents\Codex\2026-06-01\mvp-coze-codex-1-66-60\wutong\app
   ```
3. 输入：
   ```powershell
   node server.mjs
   ```
4. 看到 `wutong running at http://localhost:4173` 说明启动成功。
5. 打开浏览器，输入：
   ```text
   http://localhost:4173/
   ```
6. 如果打不开，检查终端窗口是否还开着；如果提示端口占用，先关闭旧的 `node server.mjs` 窗口再重试。

## 管理员账号初始化

1. 打开应用首页。
2. 点击右上角「医护后台」。
3. 在账号输入框输入：
   ```text
   admin
   ```
4. 在密码输入框输入：
   ```text
   123456
   ```
5. 点击「登录后台」。
6. 看到「患者总览仪表盘」说明登录成功。
7. 点击左侧「账号设置」。
8. 在「原密码」输入 `123456`。
9. 在「新密码」输入新密码。
10. 点击「保存账号密码」。
11. 看到右下角提示「账号密码已修改」说明成功。

如果登录失败，先确认是否已经修改过密码。如果忘记密码，当前原型可清空浏览器 localStorage 后恢复默认账号。

## 后台替换科室内容

1. 登录医护后台。
2. 点击左侧「流程内容配置」。
3. 修改顶部的医院名称、中心名称、提前提醒分钟和提醒文案。
4. 点击「保存提醒规则」。
5. 向下找到要修改的节点，例如「穿刺室打留置针」。
6. 修改需要的内容：
   - 节点名称
   - 到院后分钟偏移
   - 下一步科室
   - 核心操作提示
   - 标准化操作步骤
   - 禁忌与注意事项
   - 宣教图片或短视频
   - 科室实景照片
   - 文字路线指引
   - 需携带材料
7. 点击该节点下方「保存此节点」。
8. 看到右下角保存提示说明成功。
9. 点击右上角「患者端」，打开对应节点详情页。
10. 如果能看到新内容，说明实时生效。

如果没有变化，确认是否点的是该节点自己的「保存此节点」，而不是只改了输入框。

## 测试患者完整流程

1. 点击右上角「患者端」。
2. 选择检查日期。
3. 选择检查时段：上午或下午。
4. 选择是否无痛胃肠镜。
5. 输入患者姓名。
6. 输入联系电话。
7. 如需测试病史，展开「基础病史（选填）」并勾选。
8. 点击「生成我的专属流程」。
9. 看到患者专属时间线说明生成成功。
10. 点击下一步卡片里的「查看详细指引」。
11. 看到操作步骤、注意事项、宣教内容说明节点详情正常。
12. 点击「我已完成本节点」。
13. 回到时间线后，该节点变灰并显示勾号，说明完成状态正常。
14. 在时间线底部点击「我已到院报到」。
15. 看到流程切换为「院内就诊流程」说明院内导诊正常。
16. 点击任一院内节点「查看详情」。
17. 看到下一步科室、科室照片占位、路线指引、需携带材料，说明院内节点正常。
18. 返回时间线，点击「检查已完成」。
19. 看到术后注意事项页，说明患者全流程跑通。

## 测试医护后台

1. 点击「医护后台」并登录。
2. 在「患者总览仪表盘」查看刚才录入的患者。
3. 用检查日期筛选一次。
4. 用姓名或电话搜索一次。
5. 点击患者行里的「查看/调整」。
6. 修改检查日期、检查时段或节点完成情况。
7. 点击「保存调整」。
8. 回到患者端，看到时间线变化说明调整生效。
9. 在后台点击「发送提醒」或「批量模拟微信提醒」。
10. 看到「消息发送记录」新增一条，说明提醒模拟正常。
11. 点击「模拟跳转」。
12. 页面跳到患者对应节点详情，说明消息跳转逻辑正常。
13. 点击「基础数据统计」。
14. 点击「导出Excel表格」。
15. 浏览器下载 CSV 文件；用 Excel 打开即可查看。

## 正式上线前不能跳过的事

- 申请并认证微信小程序。
- 配置微信订阅消息模板。
- 接入用户授权和真实发送接口。
- 接入云数据库或医院认可的数据库。
- 做服务端加密、HTTPS、审计日志、备份恢复。
- 让医院信息科确认数据安全和部署方式。
