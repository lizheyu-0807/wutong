## 验证结果

已验证：

- 患者创建后能生成专属时间线。
- 上午场按时间顺序显示 20:00、02:00、04:00、07:30。
- 节点详情包含操作步骤、注意事项、宣教内容。

- 院内节点包含下一步科室、照片占位、路线和材料。
- 检查完成后进入术后注意事项页。

## 当前限制

| 限制 | 说明 |
|---|---|
| 不是真实微信小程序 | 当前是 Web 原型，尚未接入微信小程序工程和 Coze 发布流程 |
| 订阅消息未真实发送 | 目前只有提醒计划和模拟发送记录 |
| 数据不适合生产 | 数据存储在浏览器 localStorage，只适合演示 |
| 上传素材仅本机有效 | 图片/视频以浏览器本地数据保存，不是服务器素材库 |
| 权限很轻 | 只有单管理员账号，没有审计和角色隔离 |
| 成本为估算 | 正式采购需以云厂商控制台为准 |

## 数据兼容

`wutong/app/core.js` 默认使用 `wutong-state` 作为浏览器本地存储 key。为了不丢失整理前的演示数据，它也会尝试读取旧原型的 `endoscopy-mvp-state`，但新保存会写入 `wutong-state`。

5. 将图片/视频上传改为对象存储。
