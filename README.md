# wutong 应用操作说明

## 先说结论

这个交付物可以用于科室内部试点前的流程验证：患者录入、个性化时间线、节点详情、院内导诊、术后宣教、医护后台、内容配置、提醒计划、手动提醒模拟、统计和导出都能本地跑通。

它还不等于正式微信小程序上线版本。真实微信订阅消息必须在微信公众平台配置 AppID、订阅消息模板、用户授权、服务器域名和发送接口；正式医疗数据合规也必须改为服务端加密存储、HTTPS、访问审计和备份。本原型的本地存储只用于演示。

## 打开应用

最稳妥方式是用本地服务器打开。

1. 打开终端，进入本目录。
2. 输入：
   ```bash
   node server.mjs
   ```
3. 看到类似 `wutong running at http://localhost:4173` 说明启动成功。
4. 在浏览器打开终端显示的地址。
5. 如果打不开，检查终端是否还在运行；如果端口被占用，按终端提示换另一个地址。

## 管理员账号初始化

1. 打开应用首页。
2. 点击右上角「医护后台」。
3. 在账号输入框输入：`admin`
4. 在密码输入框输入：`123456`
5. 点击「登录后台」。
6. 看到「患者总览仪表盘」说明登录成功。
7. 点击左侧「账号设置」。
8. 输入原密码 `123456`，再输入新密码。
9. 点击「保存账号密码」。
10. 看到右下角提示「账号密码已修改」说明成功。

如果登录失败，先确认是否已经改过密码；如果忘记密码，可在浏览器开发者工具里清空本站 localStorage 后重新打开，账号会恢复默认值。

## 后台替换科室内容

1. 登录医护后台。
2. 点击左侧「流程内容配置」。
3. 先修改顶部的医院名称、中心名称、提前提醒分钟和提醒文案。
4. 点击「保存提醒规则」。
5. 向下找到要改的节点，例如「穿刺室打留置针」。
6. 修改：
   - 节点名称
   - 到院后分钟偏移
   - 下一步科室
   - 操作步骤
   - 禁忌与注意事项
   - 宣教图片或短视频
   - 科室实景照片
   - 路线指引
   - 需携带材料
7. 点击该节点下方「保存此节点」。
8. 看到右下角保存提示说明成功。
9. 回到「患者端」，打开对应节点详情页，能看到新内容说明已实时生效。

如果图片没有变化，确认是否点了该节点自己的「保存此节点」。上传大视频可能超过浏览器本地存储容量，正式上线应改为服务器素材地址。

## 测试完整患者流程

1. 点击右上角「患者端」。
2. 选择检查日期。
3. 选择检查时段：上午或下午。
4. 选择是否无痛胃肠镜。
5. 输入患者姓名。
6. 输入联系电话。
7. 如需测试病史，展开「基础病史（选填）」并勾选。
8. 点击「生成我的专属流程」。
9. 看到患者专属时间线说明生成成功。
10. 点击下一步卡片里的「查看详细指引」。
11. 看到操作步骤、注意事项、宣教内容说明节点详情正常。
12. 点击「我已完成本节点」。
13. 回到时间线后，该节点变灰并显示勾号，说明完成状态正常。
14. 在时间线底部点击「我已到院报到」。
15. 看到流程切换为「院内就诊流程」说明院内导诊正常。
16. 点击任一院内节点「查看详情」。
17. 看到下一步科室、科室照片占位、路线指引、需携带材料，说明院内节点正常。
18. 返回时间线，点击「检查已完成」。
19. 看到术后注意事项页，说明患者全流程跑通。

## 测试医护后台

1. 点击「医护后台」并登录。
2. 在「患者总览仪表盘」查看刚才录入的患者。
3. 用检查日期筛选一次。
4. 用姓名或电话搜索一次。
5. 点击患者行里的「查看/调整」。
6. 修改检查日期、检查时段或节点完成情况。
7. 点击「保存调整」。
8. 回到患者端，看到时间线变化说明调整生效。
9. 在后台点击「发送提醒」或「批量模拟微信提醒」。
10. 看到「消息发送记录」新增一条，说明提醒模拟正常。
11. 点击「模拟跳转」。
12. 页面跳到患者对应节点详情，说明消息跳转逻辑正常。
13. 点击「基础数据统计」。
14. 点击「导出Excel表格」。
15. 浏览器下载 CSV 文件；用 Excel 打开即可查看。
